# Keyboard Shortcuts

Press `H` inside the app to see this list at any time.

| Key | Action |
|---|---|
| `Space` | Play / pause auto-rotation |
| `R` | Reset & fit view |
| `1` `2` `3` `4` | Ball & Stick · Space Fill · Wireframe · Licorice |
| `7` `8` `9` `5` | Camera: front · top · right · isometric |
| `←` `→` `↑` `↓` | Orbit camera |
| `+` / `−` | Zoom in / out |
| `B` | Toggle bonds |
| `X` | Toggle simulation box |
| `L` | Toggle element labels (≤400 atoms) |
| `G` | Cycle lighting preset (studio → lab → outdoor → space → soft) |
| `T` | Toggle dark / light theme |
| `O` | Toggle sidebar |
| `S` | Save PNG screenshot |
| `H` or `?` | Shortcut overlay |
| `Esc` | Close panels / overlays |

Mouse/touch: orbit = drag · zoom = wheel / pinch · hover an atom for details.

Shortcuts are ignored while you're typing in the paste-data box.
